# Hardware and Software used in the project
## Hardware used
1. Arduino Nano with Atmel ATMega328P MCU and soldered male pins
2. 16x2 LCD screen compatible with Hitachi HD44780 display drivers
3. 10k&#8486; linear potentiometer
4. 220&#8486; resistor
## Software used
1. For editing the code and programming the MCU: Arduino IDE v. 1.8.19 (legacy)
2. For 3D modelling: Autodesk Fusion
3. For slicing: ELEGOO Cura
## Additional components, instruments and materials
1. Philipps screwdriver
2. ELEGOO Neptune 3 Pro 3D printer + PLA filament
3. USB type A to USB type Mini-B cable
